# Kotcha

> Kotcha is a consumer running-coaching mobile application operated by PACEUP SAS (Paris, France),
> co-founded with marathon world-record holder Eliud Kipchoge and the NN Running Team. It generates
> personalized, adaptive training plans for 5K, 10K, half-marathon and marathon distances through a
> conversational AI coach, and imports activity and health data from Strava, Garmin Connect, Apple,
> Coros and Huawei devices. Kotcha publishes NO public API, NO developer portal and NO
> machine-readable API contract; it is distributed as an iOS/Android subscription app.

## Status

- No API: Kotcha declares no API in this profile. As of 2026-08-17 there is no developer portal, no
  API reference, no OpenAPI/AsyncAPI/GraphQL contract, no MCP server and no A2A agent card. Kotcha is
  an API *consumer* (Garmin Connect, Strava, Apple Health) rather than an API producer.
- Automated access is prohibited: Kotcha's Terms & Conditions forbid "accessing services through
  unauthorized means or automated methods". Do not attempt to call the mobile application backend.
- Correction welcome: if Kotcha publishes a developer program, open an issue on this repository and
  the profile will be re-run and re-scored.
